№ 04 · Компоненти

Базові вузли

Кнопки

Округлені — pill (тільки для основних дій). Звичайні — гострі кути. Mono-кнопка — для технічних дій (експорт, копіювання ТТН).

.btn · .btn--primary · .btn--safelight · .btn--ghost · .btn--mono

Поля вводу

Лейбли — у JetBrains Mono UPPERCASE, як на лабораторній картці. Фокус — тонке кольцо в графіті, без яскравих обрамлень.

.input · label + input

Картка набору

Базова картка — без тіні, з тонкою рамкою. Лейбли — Mono UPPERCASE. Назва — Cormorant. Hover змінює рамку, не тінь.

.card · .card-eyebrow · .card-title · .card-body · .card-meta

№ 05 · Рух

Повільність — як хімія

Рух у ПРОЯВ — повільніший, ніж стандартні UI-анімації. Зображення проявляються, не «з'являються». Елементи виходять у кадр, не «всплывают». Три головні easing-функції покривають усі стани.

PHOTO LOAD Проявлення
1 200 ms · ease-emerge · blur 8 → 0 px

Для появи фото після завантаження. Імітує мокру фотопластину, що сохне в фіксері.

UI ENTRY Вихід у кадр
320 ms · cubic-bezier(.22,1,.36,1)

Дефолтна анімація появи UI: панелі, тости, кроки. Швидко, але без посмикувань.

STATE Затемнення
180 ms · cubic-bezier(.4,0,.2,1)

Для змін стану кнопок, hover, focus. Найшвидша — реакція має бути миттєвою.
